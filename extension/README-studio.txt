Faircopy Studio

This is the studio desk. There is no passcode and no usage report.
Nothing is uploaded. Do not publish this copy.

Install
1. Unzip. Do not drag the zip onto Chrome.
2. Open the folder that appears. It must contain manifest.json and desk.html together.
3. Open chrome://extensions and remove any older Faircopy Studio.
4. Turn on Developer mode.
5. Drag that folder onto the page, or choose Load unpacked.
   If Chrome says the manifest is missing, you dragged the outer folder or the zip. Go one level in, to the folder that holds manifest.json.
6. Click the Faircopy Studio icon.

Chrome 151 or newer can also open a full-page PDF in Faircopy Studio.
A PDF inside a web page still uses Chrome’s viewer.
