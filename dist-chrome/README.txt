Install
1. Unzip. Open the Faircopy folder. It contains manifest.json and desk.html.
2. Open chrome://extensions and remove any older Faircopy.
3. Turn on Developer mode.
4. Drag that folder onto the page, or choose Load unpacked.
5. Click the Faircopy icon.

Chrome 151 or newer can also open a full-page PDF in Faircopy.
A PDF inside a web page still uses Chrome’s viewer.
