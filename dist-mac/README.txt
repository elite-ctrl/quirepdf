Install Quire for Mac

1. Unzip this folder.
2. Right-click "Install Quire" and choose Open. If macOS asks, choose Open again.
3. When it finishes, Quire is in your Applications folder.
4. Double-click a PDF. A Terminal window opens and the PDF opens in Quire.
5. Leave that Terminal window open while you work. Close it when you are finished.
6. If a PDF still opens in Preview, right-click it, choose Open With, then Quire, and tick Always Open With.

The first time, macOS may say the app is from an unidentified developer. Right-click it and choose Open. That is expected. Quire is not from the App Store.

To remove Quire, double-click Uninstall Quire in your Applications folder.

The first PDF on a new computer still needs your passcode. This computer remembers it after that.
Your PDFs and marks stay on this computer. Nothing is uploaded.
Open the same PDF again on this computer and the marks come back.

Quire needs Python 3. If it is missing, install it from python.org and run Install Quire again.
